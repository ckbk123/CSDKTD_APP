CSDKTD APP - initial interface preview

Windows: open bin\CSDKTD APP.exe. No installer or .NET runtime is required.
A working Vulkan graphics driver is required. The Vulkan SDK is not needed
to run the application. Keep this folder's licenses and notices with copies.

Choose Continuous or Discrete, select a topic, then open a module card.
All 56 modules open inside the same window. They currently contain a default
example description and a blank workspace for later educational tools.
Mathematical solvers and interactive plots have not been implemented yet.

Use All modules or Esc to return. Ctrl+F focuses search; Ctrl+Home returns
to the current section's overview. Reset example restores the local baseline.
No examples, progress or sessions are saved.

This preview was tested on Windows 11 x64. Other Windows versions, Linux
and macOS require separate build/runtime validation.

Source and development instructions:
https://github.com/ckbk123/CSDKTD_APP
